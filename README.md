# URL Shortener & Real-Time Analytics

A production-style URL shortening service built with Go, PostgreSQL, Redis, Kafka, ClickHouse, and React.

## Current Status

 Early development

## Planned Features

- URL shortening
- Custom aliases
- URL expiration
- Redis-first redirects
- User authentication
- API keys
- Rate limiting
- Async click analytics
- Kafka event pipeline
- ClickHouse analytics
- React analytics dashboard
- Prometheus + Grafana observability
- Automated testing
- Load testing with k6
- CI/CD

## Architecture

The project will evolve from a simple Go + PostgreSQL URL shortener into a distributed system with caching, asynchronous analytics processing, and observability.
